# MGC YFC Operations 0.30.0

- Adds administrator-only Application Settings > Page Colors.
- Administrators can set page/header colors and separate page backgrounds for light and dark mode. Changes are saved on the server and apply to everyone, including page-menu buttons and the browser theme color.
- Automatically selects readable header text for the chosen color. Default colors can be restored from the same screen.
- Changes Print with a Purpose to #073ea6 by default.

On the server, install and restart, then refresh browsers. The in-app update includes these web/API changes; the full Windows installer is also available for reinstalling over the existing location. Do not uninstall the server first.

Windows applications remain unsigned; code signing is still deferred.
