# MGC YFC Operations 0.37.1

- The schedule week now starts on Sunday.
- Shifts have a Job field. Managers and administrators can assign multiple jobs and work sites in Users → Work assignments and select one primary job and work site. New shifts default to the employee's primary assignments.
- Clock-in and clock-out location checks are assigned per employee. When enabled, punches must come from one of that employee's assigned work sites.

The previous global location setting does not carry over. Enable location checks in Work assignments for each employee who needs them. Existing work sites and past punch records are retained.

Use Check for Updates on an existing server, or run the full Windows installer over the current installation.
