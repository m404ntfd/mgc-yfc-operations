# MGC YFC Operations 0.38.2

- Shows progress when adding a user, prevents duplicate submissions while the request is pending, and reports success or an error.
- Defaults weekly overtime to 40 hours and flags shifts of 5.5 hours or more with no recorded break. Both thresholds are editable in Payroll Export. Recorded breaks are excluded before calculating regular and overtime hours by default.
- Renames Login & legal names to Employee Profile and moves Edit display name into that dialog.

Use Check for Updates on an existing server, or run the full Windows installer over the current installation.
