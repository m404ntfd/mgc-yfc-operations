# MGC YFC Operations 0.35.2

- Adds Edit name in Settings → Application Settings → Users. A rename keeps the existing account, password, permissions, messages, and receipt ownership.
- Administrators can grant Edit user names in Roles. Administrator accounts can be renamed only by an administrator.

Use Check for Updates on the server if you already installed the full 0.35.1 installer. If you are upgrading from 0.34.x or earlier and want desktop and mobile push notifications, install the full 0.35.2 Windows installer over the existing server installation.
